# ذائقة — نموذج ترشيح عطور مستقل

واجهة عربية RTL مناسبة للجوال، بثلاثة اختيارات (جنس العطر، العائلة، المناسبة)، ثم ثلاثة عطور وأسباب كل ترشيح وروابط تفاصيل تجريبية قابلة للفتح.

## تجربة النسخة

افتح `demo.html` مباشرة في المتصفح؛ يعمل دون تثبيت أو شبكة أو مفاتيح سلة. أو من هذا المجلد:

```sh
npm start
# http://localhost:4173
npm test
npm run build
```

`demo.html` نسخة مجمعة من الملفات المصدر، أعد بناءها بعد أي تعديل. لا يتم إرسال الإجابات أو تخزين بيانات العملاء. متجران افتراضيان، في كل منهما 30 منتجًا افتراضيًا. الروابط تفتح تفاصيل المنتج داخل الصفحة، وليست روابط شراء حقيقية.

## النطاق والاستقلال عن الثيم

أكدت مراجعة `../../README.md` و`../../twilight.json` أن المشروع الأصلي مخصص لثيم Twilight، وليس تطبيق سلة. تمت الاستفادة من RTL وبطاقات المنتجات وحقول الاسم والسعر والرابط والتوفر الموثقة في `src/views/pages/product/single.twig`. جميع ملفات النموذج هنا مستقلة عن Twig وTwilight وحزم الثيم، ولا تغير واجهته أو إعداداته. يمكن نقل المجلد إلى مستودع تطبيق مستقل كما هو. وجوده هنا للمراجعة لا يحوله إلى تطبيق مثبت في سوق سلة.

## البنية

- `catalog.js`: بيانات افتراضية منفصلة بمفتاح `storeId`، وقواميس التصنيف العربية.
- `engine.js`: محرك مستقل وواجهة `DemoCatalogProvider.getCatalog(storeId)`؛ لا يعتمد على DOM.
- `app.js`: واجهة المستخدم والتبديل بين الكتالوجات ومسارات تفاصيل المنتجات.
- `index.html` و`styles.css`: واجهة دون تبعيات خارجية أو خطوط مستضافة.
- `engine.test.cjs`: اختبارات منطقية دون أسرار أو شبكة.

عقد المنتج الموحد:

```js
{
  id: 'store-local-product-id',
  storeId: 'tenant-id',
  name: 'اسم المنتج',
  gender: 'male', // male | female | unisex
  families: ['citrus'], // citrus | powdery | woody | floral | oriental | gourmand
  occasions: ['daily', 'work'], // daily | work | evening | gift
  notes: 'برغموت · ليمون',
  price: 185, currency: 'SAR', size: 50,
  available: true,
  url: 'https://merchant.example/products/123',
  color: '#d8bb69', demo: false
}
```

المعرف الفريد مستقبلًا هو `(storeId, id)`، وليس معرف المنتج منفردًا. تعيد طبقة الكتالوج نسخًا من البيانات ويستبعد المحرك أي سجل تابع لمتجر مختلف حتى عند تكرار المعرفات.

## منطق الترشيح وحدوده

هذه نسخة بقواعد مطابقة قابلة للتفسير، وليست نموذج تعلم آلة أو اتصالًا بنموذج لغوي. العائلة 60 نقطة، المناسبة 25، جنس مطابق 15 أو منتج للجنسين 8. النقاط للترتيب وليست نسبة ثقة أو وعدًا بالإعجاب. الأولوية للعائلة، ثم المناسبة، مع ترتيب ثابت عند التعادل.

جنس العطر قيد صارم: الرجالي والنسائي يقبلان منتجات للجنسين، واختيار للجنسين يعرض هذا التصنيف فقط. المخزون والتاجر والرابط الآمن والسعر الصالح قيود صارمة كذلك. الأسباب مشتقة من بيانات المنتج، ولا تدعي تطابقًا غير موجود. عند نقص المطابقات تعرض بدائل مع بيان الاختلاف؛ عند نقص المنتجات المؤهلة تعرض العدد المتاح دون تكرار. تُمسح النتائج عند تعديل أي اختيار أو تبديل المتجر.

## الربط اللاحق بمتاجر سلة

1. إنشاء تطبيق مستقل وخادم لإدارة تثبيت كل تاجر وتسجيل دخوله؛ إجراء مراجعة الوثائق الرسمية الحالية قبل التنفيذ.
2. تخزين رموز OAuth مشفرة في الخادم وربطها بهوية التاجر الموثقة؛ لا توضع أسرار في المتصفح.
3. كتابة مزود خادمي ينفذ `getCatalog(authenticatedTenantId)` ويحيل كتالوج التاجر إلى العقد الموحد؛ لا يثق الخادم بمعرف متجر مرسل من المتصفح كإذن وصول.
4. فصل جداول المنتجات والتصنيفات ومفاتيح التخزين المؤقت والمزامنة لكل متجر؛ رفض أي عدم تطابق في هوية التاجر. مزامنة التوفر والسعر والرابط من المصدر وتحديد سياسة تحديث.
5. مراجعة تصنيف العائلة والمناسبة والنوتات من التاجر. لاحقًا يمكن لنموذج لغوي اقتراح التصنيفات بمراجعة بشرية، ولا يخترع منتجات أو روابط خارج الكتالوج.
6. توفير واجهة مستضافة مستقلة ورابط أو عنصر تضمين اختياري بحسب إمكانات سلة المدعومة؛ الثيم مجرد نقطة عرض قابلة للاستبدال.
7. قبل الاستخدام التجاري: اختبار OAuth، العزل في الخادم، إلغاء التثبيت، مزامنة المخزون، الروابط والخصوصية، ثم مراجعة النسخة التجريبية مع المالك. لم ينفذ أي من ذلك في هذا النموذج.

## التحقق

نجحت 9 مجموعات اختبارات، تشمل جميع 144 تركيبة تفضيلات عبر المتجرين (72 لكل متجر)، وثبات الترتيب، وعزل الكتالوجات، واستبعاد غير المتاح، والروابط غير الآمنة، والبيانات غير الصالحة، ونقص الكتالوج، وصدق تفسيرات البدائل.

تعذر تشغيل فحص المتصفح الآلي في بيئة التنفيذ بسبب منع إنشاء socket لعملية Chromium؛ لذا لم يكتمل التحقق البصري الآلي. الواجهة تستخدم نقاط استجابة للجوال، ويلزم مراجعتها يدويًا في المتصفح قبل الاعتماد.

لم يُنشر النموذج في متجر حقيقي، ولم يتصل بأي حساب سلة.
